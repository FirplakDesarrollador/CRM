# INC-2026-009 - Campos editables se perdían por desalineación entre cliente, pull y esquema Supabase

- Fecha: 2026-09-04
- Flujo critico: R2
- Estado: CORREGIDO

## Impacto

Los usuarios podian escribir comentarios de contactos/cotizaciones y campos
logisticos F-V-29 que parecian guardados en IndexedDB, pero no existian en el
esquema remoto. Un pull posterior tambien reemplazaba registros locales con
proyecciones incompletas. Se afectaban `CRM_Contactos`, `CRM_Cotizaciones`,
`CRM_Pedidos` y el campo `origen_cuenta` de `CRM_Cuentas`.

## Causa raiz

1. Los formularios y modelos locales evolucionaron sin una migracion aplicada
   de forma completa en Supabase.
2. El RPC de snapshots ignora claves sin columna, por lo que podia confirmar la
   mutacion aunque el dato editable no se persistiera.
3. Los pulls de cuentas, contactos y cotizaciones reconstruian objetos mediante
   allowlists obsoletas. `Dexie.bulkPut()` reemplazaba el registro y eliminaba
   campos que el servidor si habia devuelto.

## Prevencion

- Migracion append-only e idempotente para las columnas editables faltantes.
- Inclusión explicita de `origen_cuenta` y `comentarios` en los mapeos de
  cuentas/contactos.
- Conservacion del registro remoto completo para cotizaciones.
- Contrato estatico permanente que vincula migracion y pull.

## Deteccion permanente

- Prueba que falla antes de la correccion: `lib/persistence-contracts.test.ts`
  (3/3 casos RED).
- Etapa QA que la ejecuta: `focused-tests` y `product-tests` dentro de
  `npm run qa:gate`.
- Identidad estable del caso: `contratos de persistencia de campos editables`.

## Evidencia

- Esquema remoto consultado por OpenAPI/Data API en modo read-only.
- RED: `npm run qa:focused -- lib/persistence-contracts.test.ts` -> 3 fallos.
- GREEN: el mismo comando -> 3/3 casos aprobados.
- Migracion: `20260904193842_persist_crm_editable_fields.sql`.
- Pull corregido: `lib/sync.ts`.

## Riesgo residual

La migracion se entrega en control de versiones, pero no se aplica directamente
a produccion en este cambio. El replay de una base desechable sigue dependiendo
de la configuracion externa del entorno QA. Los campos SAP heredados que no se
usan en las rutas editables actuales no se rediseñan en este incidente.
